# Meme Matcher

Build a full-stack web application called "Meme Tinder" where users swipe through memes like Tinder.

Requirements:
- Swipe right = like, swipe left = dislike
- Save button
- Alternative buttons for like, dislike, and save
- Saved memes page
- User profile page with statistics (total swiped, liked, disliked, saved)
- After the user likes 10 memes, show a "matches" page (top humor match / meme compatibility personality)
- Responsive web UI optimized for both desktop and mobile
- Use Supabase/Lovable Cloud for persistent database schema and meme data
- Do not implement any AI functionality
- Curate/seed a starter set of clean Russian and English memes
- Start with the database schema (memes, user interactions/swipes, saved memes) and core swiping structure without unnecessary bloat
